# 小悠办公 Agent Demo

当前主版本：**2026-10-27 · 三栏导航与重复工作 Skill 演示版**。保留灰白工作台，增加项目与会话管理、页面状态恢复、任务复杂度预估，以及默认可见的重复工作识别示例。对话采用深色用户气泡、彩色子 Agent 标签、成果预览卡和白底摘要。

## 怎么看最新版

- **无需启动服务：** 下载仓库 ZIP，解压后用浏览器打开 `frontend/程小悠.html`。这是包含全部脚本、样式和素材的单文件。
- **开发预览：** 在仓库根目录运行 `python3 -m http.server 8771 --bind 127.0.0.1`，访问 `http://127.0.0.1:8771/frontend/#home`。
- **更新单文件：** 修改源码后运行 `python3 frontend/build-standalone.py`，刷新原页面即可。

`frontend/index.html` 是开发入口，需要 HTTP 服务。`frontend/程小悠.html` 才是可直接双击的交付文件。保留“程小悠”文件名是为了兼容原有本地地址；界面品牌统一叫“小悠”。不同文件位置、浏览器和地址的本地数据互相独立。

## 当前主要功能

| 模块 | 主要体验 |
| --- | --- |
| 首页与办公对话 | 多页面标签、模型选择、附件、执行环境、操作确认、语音输入、后续提问建议；能力范围按钮选中后随消息带入，不自动填提示词。 |
| 个人助理小悠 | 独立长期对话、按短句逐条回复、正在输入状态、事项卡片、能力、日记、上下文、设置；工作完成可提示未读。记忆默认开启，小悠设置不展示记忆入口或开关。 |
| 团队空间 | 创建空间、邀请成员、管理角色；创建者与管理员维护插件、助理、知识库及关联。成员直接使用预配置助理，任务与对话仍为个人所有。 |
| 助理 | 一句话创建、已安装/我创建的管理、固定到左侧、持续对话、分享入口、后续配置与创建者数据看板。数据看板使用示例数据。 |
| 任务中心 | 任务看板、飞书待办、自动化任务；保留编排、子智能体过程、验收、确认、恢复与回放。 |
| 插件与技能 | 插件、Skill、MCP 管理，推荐工作方法，支持为助理补充能力。 |
| 站点 | 创建、发布、打开、复制链接、继续修改；发布状态和内容保存在本地浏览器。 |
| 远程控制 | 更多菜单与首页飞书横幅入口，包含私聊/群聊配置及办公场景入口。 |

侧栏最上方为「新建对话」，「小悠」以普通导航行呈现。功能栏可展开，项目、置顶会话和最近对话集中管理；市场通过标签切换助理、插件、技能和 MCP。首页已精简团队空间卡片与输入框下方的灰色提示区。

## 建议演示顺序

1. 首页交办一项分析或写作任务，查看对话中的复杂度与预估等待时间。
2. 选取「资料来源」，切换顶部标签后返回，检查草稿、所选来源和阅读位置。
3. 打开置顶的「经营周报 · 重复工作识别示例」：已有三周连续对话，默认展示识别说明和「保存为 Skill」。可修改并保存私人待审核草稿；合成示例与真实工作计数隔离。
4. 从任务中心进入会话，点击报告成果卡，预览文档、数据表或网页，查看右侧摘要与子 Agent 过程。

完整演示包可在构建后生成：`python3 scripts/package_demo.py --output /path/to/xiaoyou-demo.zip`。解压后双击包根目录的 `小悠办公Agent.html` 即可演示；包内也保留源码、素材、测试和启动说明。

这是**本地交互原型**。模型生成、企业授权、后台调度、远程执行、跨用户分享、业务查询与创建者使用统计不代表已接入真实服务。飞书待办保留接入适配入口；没有配置实际服务时使用明确标记的示例数据。浏览器会话和用户本地数据不随仓库上传。

## 目录

- `frontend/src/`：业务逻辑与页面渲染模块。
- `frontend/*.css`：样式；主视觉以 `trae-design.css` 及后续对应模块样式为准。
- `frontend/assets/`：海豚形象、飞书图标等实际使用素材。
- `frontend/程小悠.html`：最新可直接打开的主版本。
- `frontend/build-standalone.py`：从模块源码生成单文件。
- `scripts/package_demo.py`：打包当前可直接打开的 HTML、源码、素材与测试，并生成文件校验清单。
- `frontend/PERSONAL-ASSISTANT.md`：个人助理合并说明。
- `frontend/README.md`、`frontend/MERGE-NOTES.md`：早期迭代与合并记录，其中旧入口描述仅作历史参考；最新入口以本页和实际界面为准。
- `frontend/程小悠-Lovable视觉版.html`：2026-10-26 视觉对比快照，**不是最新功能主版本**。
- `frontend/design-variants/`：视觉对比版的样式与构建脚本。
- `tests/`：当前版本回归检查。
- `versions/`、`screenshots/`、`verification-v15.json`：原仓库保留的历史快照与旧版验证记录，不代表当前版验证结果。

## 检查与协作

需要 Node.js 24 和 Python 3；没有 npm 依赖和 API Key 要求。

```sh
python3 frontend/build-standalone.py
node --test tests/*.mjs
```

提交前执行上述构建与全量检查，并在浏览器确认首页、标签页、成果卡和默认 Skill 演示。浏览器状态和业务状态测试覆盖范围不同，测试通过不代表真实外部服务已经接通。
